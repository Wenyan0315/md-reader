# 欢迎使用 MD Reader

这是一个本地 Markdown 阅读器，专门为「把一堆 .md 文件读舒服」而设计。

## 快速上手

1. 点击右上角 **打开文件夹**，选择你存放 md 文件的项目目录（推荐 Chrome / Edge 浏览器）。
2. 或者点击 **选择文件**，手动挑选一个或多个 .md 文件。
3. 也可以直接把 .md 文件**或整个文件夹拖进窗口**，自动导入并合并到当前列表。
4. 左侧栏支持按文件名搜索；右侧宽屏时自动显示文章目录，点击可跳转。

## 功能一览

- **文件夹浏览**：递归读取目录下的所有 .md 文件（自动跳过 node_modules、.git 等目录，上限 500 个文件）。
- **文件搜索**：左侧搜索框按路径过滤。
- **文章目录（TOC）**：自动从 h1–h3 标题生成，点击平滑滚动。
- **GFM 语法**：表格、任务列表、删除线等都支持。
- **深浅色切换**：右上角月亮 / 太阳图标。
- **本地优先**：文件在你浏览器内直接读取，不会上传到任何地方。

## 内置文档

本应用内置了两篇演示文档（就是你现在看的这些），方便你预览排版效果。想读自己的文件，随时用右上角按钮切换数据源即可。
